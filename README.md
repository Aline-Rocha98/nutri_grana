# 💰 NutriGrana

# 📌 Project Overview

🚧 **Under Development**

**NutriGrana** is a personal project developed with the goal of creating a personal finance management platform, allowing users to have greater control over their financial activities.

The application allows users to create an account, track their expenses, register payments, organize future financial entries, and have a clearer overview of their financial life.

---

# 🏗️ Project Architecture

The project follows an architecture based on the separation of responsibilities, aiming to improve code organization, maintainability, scalability, and future evolution.

# Specific Objectives

- Allow user registration and authentication;
- Register income and expenses;
- Manage future financial entries;
- Record completed payments;
- Categorize financial transactions;
- Create financial dashboards and indicators;
- Help users analyze their financial habits.
