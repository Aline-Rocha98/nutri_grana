# 💰 NutriGrana

# 📌 Project Overview

🚧 **Under Development**

**NutriGrana** is a personal project developed with the goal of creating a personal finance management platform, allowing users to have greater control over their financial activities.

The application allows users to create an account, track their expenses, register payments, organize future financial entries, and have a clearer overview of their financial life.

---

# 🏗️ Project Architecture

The project follows an architecture based on the separation of responsibilities, aiming to improve code organization, maintainability, scalability, and future evolution.

# Specific Objectives

- Allow user registration and authentication;
- Register income and expenses;
- Manage future financial entries;
- Record completed payments;
- Categorize financial transactions;
- Create financial dashboards and indicators;
- Help users analyze their financial habits.

---

## Frontend

# 📌 Visão geral do projeto

🚧 Em desenvolvimento

O **NutriGrana** é um projeto pessoal desenvolvido com o objetivo de criar uma plataforma de gestão financeira pessoal, permitindo que usuários tenham maior controle sobre suas movimentações financeiras.

A aplicação permite que usuários realizem seu cadastro, acompanhem seus gastos, registrem pagamentos, organizem lançamentos futuros e tenham uma visão mais clara sobre sua vida financeira.

---

# 🏗️ Arquitetura do projeto

O projeto utiliza uma arquitetura baseada na separação de responsabilidades, buscando facilitar manutenção, escalabilidade e organização do código.

## Objetivos específicos

- Permitir cadastro e autenticação de usuários;
- Registrar receitas e despesas;
- Controlar lançamentos futuros;
- Registrar pagamentos realizados;
- Categorizar movimentações financeiras;
- Criar dashboards e indicadores financeiros;
- Facilitar a análise dos hábitos financeiros do usuário.
